# 🧠 News Category Classifier (TF-IDF + Logistic Regression + Streamlit)

A machine learning project that classifies news articles into **World**, **Sports**, **Business**, or **Science/Technology** categories.  
This project combines **NLP**, **machine learning**, and an interactive **Streamlit web app** to provide real-time news classification with confidence scores.

---

## 🚀 Features

✅ **Text Preprocessing**
 Lowercasing, punctuation removal, and stopword filtering  
 Clean and efficient preprocessing for better accuracy  

✅ **Vectorization**
 Uses **TF-IDF Vectorizer** to convert news text into numerical features  

✅ **Model**
 Trained with **Logistic Regression** on the AG News dataset  

✅ **Evaluation**
 Accuracy and detailed classification report  

✅ **Interactive App**
 Built with **Streamlit** for real-time prediction and confidence visualization  

✅ **Confidence Visualization**
 Displays prediction confidence with bar charts and progress bars
